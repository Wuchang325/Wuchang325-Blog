# Waline client 3.16.1

These files are copied without modifications from the official `@waline/client@3.16.1` npm archive:
https://registry.npmjs.org/@waline/client/-/client-3.16.1.tgz

The archive SHA-512 integrity was checked against npm registry metadata before extraction.
`waline.umd.js` and `waline.css` must be upgraded together. The included LICENSE covers these files.
The comment configuration loads them lazily from the blog origin, avoiding a runtime dependency on a public package CDN.
