# 看板娘

本站使用去桌子的伊蕾娜 Live2D 模型，在支持精细指针、悬停且宽度至少为 1280px 的设备上显示。人物贴住左下沿，不占正文布局空间。

## 使用与配置

`src/config/mascotConfig.ts` 管行为，`src/data/mascot.ts` 管模型资料。本站按所有者要求显式设置 `enable: true`；未配置、`enable` 省略或为 `false` 时，解析结果为关闭。

| 字段 | 作用 |
| --- | --- |
| `enable` | 总开关；关闭后没有看板娘 DOM、样式或客户端资源引用 |
| `coreUrl` | Cubism Core 脚本地址；本站固定同源的 5.1.0 副本，没有 CDN 回退 |
| `minWidth` | 自动显示所需的最小视口宽度，默认 1280；另需 `hover: hover` 与 `pointer: fine` |
| `size` | 人物高度，提供 240、280、320px 三档，默认 280 |
| `followPointer` | 是否轻微跟随鼠标；减少动态效果时始终停用 |

内容仓可通过 `config/mascot.yaml` 覆盖行为，领域键为 `mascot`，沿用现有配置同步流程，不手工修改生成的 `src/user/user-config.ts`。例如关闭：

```yaml
enable: false
```

显示名称、模型 URL、原始画布比例和互动姿势位于 `src/data/mascot.ts`。更换模型时需要重新验证参数及构图，不能直接复用伊蕾娜的参数 ID。原有的 `expressions` 参数序列仍可用于自定义模型。按钮、提示和对白由 `src/utils/mascot/labels.ts` 集中提供中文。

## 访客操作

- 点击人物，或聚焦人物后按 Enter/Space，伊蕾娜会微笑挥手，然后回到端杯姿势。连续触发时，第 2 次会眨一只眼，第 3 次脸红垂下视线，第 5 次慌张摇头。两次触发间隔超过 1.8 秒后，从问候重新开始。减少动态效果时保留端杯姿势、静态表情和对白。
- Waline 文章「赞同」或评论爱心投票成功后，她会戴上墨镜并显示一句对白。点赞反馈可以打断点击反馈，取消投票不触发。动作和对白在约两到三秒后自动恢复。
- 悬停或键盘聚焦时显示缩小、放大和收起按钮。缩放到端点后，焦点保留在人物内，工具栏仍可操作。
- 收起后保留「显示伊蕾娜」入口。顶部栏的「显示设置」可通过「显示看板娘」完全关闭或重新开启。访客的开关、收起状态和尺寸记在本站 `localStorage`。
- 已关闭或已收起时，重新访问不会下载 Core、渲染库或模型。手机和平板即使接了鼠标、视口够宽，也会禁用看板娘并隐藏开关。
- 收起的悬浮音乐按钮与人物相交时，人物向内挪出按钮所需的空间。搜索结果、原生弹窗、图片查看器打开，或者展开的音乐面板与人物相交时，人物会暂时隐藏。鼠标移动到人物或侧栏时，人物保持可见。

## 加载与生命周期

`Layout.astro` 在 `#swup-container` 外条件引入 `Mascot.astro`。其自定义元素负责轻量入口，读取设备与访客偏好后才在空闲阶段加载固定的 Core，再动态导入 Pixi/Live2D 渲染模块。源码和包模式共用同一套组件、数据覆盖、URL/base 解析和运行逻辑。

组件样式以内联字符串输出，避免 Astro 将可选组件样式提升进共享 CSS。关闭总开关时，布局不实例化该组件；不能仅通过 CSS 隐藏来替代关闭。

切页保留一个 Canvas 和运行实例，监听 Swup 页面事件重新核对持久层的遮挡情况。收起、进入不适用视口或组件卸载会取消加载、销毁渲染器并释放纹理缓存；迟到结果不得挂回页面。

模型 JSON、MOC、纹理与物理资源由有时限、可取消的请求取得，再交给引擎读取本地 Blob URL。Core 由已有 `loadScriptOnce()` 去重并限制加载时间。失败显示重试入口，不自动循环重试。WebGL 上下文丢失时同样释放人物并提供显式重试。

页面不可见或被遮挡时暂停更新；系统减少动态效果或站点 `html.motion-reduced` 开启时停用自动运动，保留静态人物与交互。连续更新限制为 30fps，恢复时限制时间步长。没有后台轮询。

## 资源与双模式边界

本站资源在 `public/live2d/elaina/`，固定 Core 在 `public/live2d/vendor/`。原有署名与 Core 文件许可头保留，处理记录和来源见 [模型验证记录](./elaina-mascot-model-validation.md)。伊蕾娜的下方衣服原本被桌子遮住，去桌子后存在截断，因此采用贴底裁切。

待机使用模型原有的端杯姿势。问候使用与模型同目录的 `greeting-arm.webp`，参考原画重绘手部和袖口。原端杯图层退到画布下缘后，绘制的手臂沿原动作轨迹抬起，手掌绕腕部摆动。脸、头发和表情继续由 Live2D 渲染。问候素材不可用时仍可点头和触发表情。

包模式使用方需要在自己项目的 `public/` 提供模型与对应 Core，或配置有效的资源地址，并通过现有数据覆盖机制提供模型资料；不要依赖开发者桌面的路径，也不要编辑 `node_modules`。主题代码没有通过 `process.cwd()` 读取模型或主题自有文件，也没有增加独立的 Astro 接线。
