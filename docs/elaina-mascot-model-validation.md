## 资源处理

本站副本位于 `public/live2d/elaina/`。桌面原目录的 8 个文件与开始处理时的备份逐一核对，均保持原样；本站副本中除纹理外的原有文件也与原件字节一致。原有署名文件全部保留。

处理脚本为 `scripts/mascot/prepare-elaina.mjs`，在原纹理坐标 `(2540, 1356)`、大小 `1126×674` 的区域中清除 Alpha。经重新解码逐像素核对：

- 修改了 234,729 个原本非透明像素的 Alpha。
- 区域外修改为 0，所有 RGB 通道修改为 0。
- 纹理尺寸保持 4096×2048，没有重排 UV 或生成式重绘。
- 输出 PNG 采用无损自适应过滤压缩，大小 1,977,228 字节，略小于原件的 1,995,858 字节。
- `.moc3` 没有修改；桌子网格仍存在，视觉上已移除，不需要每帧覆盖部件透明度。

原始纹理 SHA-256：`ede4bdbe8d638cc2deaf3b1d04f32e75016e030510354538d800fd3e473c1599`。

去桌子纹理 SHA-256：`0ca7ba2762aa242e7ad640d2fc3b208212c88eed2662b5b49c7c8944e79fa626`。

脚本会拒绝将输出写入原模型目录，并检查尺寸和桌子非透明像素数量；输出后再验证像素不变约束。完整记录见资源目录下的 `elaina-preparation.json`。

## 渲染结果与构图

已安装并锁定 `pixi.js` 8.22.0 和 `untitled-pixi-live2d-engine` 1.4.0，使用其 `/cubism` 入口。模型、纹理、105 个 Drawable 以及物理配置都能正常加载。

原型使用官方来源的 Cubism Core 5.1.0，保存在本地验证目录，SHA-256 为 `25ae938cb4fe282ce189b357bcc97e603d1e1f7ec78bf04150d401c23cdc792f`。正式接入时需将同一运行库及其原有许可说明纳入可部署资源；当前未将本地验证目录作为主题生产依赖。

来源：[Live2D 官方 Core 地址](https://cubism.live2d.com/sdk-web/cubismcore/live2dcubismcore.min.js)。该 URL 只用于取得本次原型固定副本，页面运行时从本地加载。

重要构图发现：模型声明画布是 700×900，但桌子 `ArtMesh108` 实际大致位于模型坐标 `x=-187…937`、`y=896…1568`。如果只按声明画布裁切，原版桌子也会被遮住。因此完整对照展开了画布外的真实几何范围，能够确认原版有桌子而处理后没有桌子。

去桌子后，下方衣服与飘带的原有截断会露出。它适合贴视口下沿显示，不适合整个人物悬空摆放。280px 模式以原画布比例 `280 / 900` 渲染，并在画布下沿裁切，能形成自然的半身效果；最终接入仍需在博客真实侧栏和悬浮层旁检查避让。
