# 伊蕾娜看板娘第一版规划

日期：2026-11-03；接入完成于 2026-11-04。状态：模型原型与全站第一版接入已完成。本站仅中文，采用现成渲染库，直接修改模型资源副本移除桌子。原型证据见 [模型原型验证](./elaina-mascot-model-validation.md)，最终行为、配置和验证见 [看板娘说明](./mascot.md)。

## 目标与第一版范围

使用 `C:\Users\Wuchang325\Desktop\LSS` 中的 Live2D 模型，显示名称为「伊蕾娜」。第一版交付去除桌子的半身看板娘，放在桌面端左下角，具有自然眨眼、轻微呼吸、视线跟随、点击表情、缩放和收起能力。阅读与页面导航优先，人物不占正文布局空间。

第一版不加入自动弹话、语音、聊天、拖拽、多模型切换或远程模型市场。本站只提供中文，按用户本次明确要求，不为此功能补齐十种语言。显示名称、按钮、提示与无障碍名称集中提供中文文案，不在组件各处散落重复字符串；不改动站点既有语言机制。

## 已核实的基础

- 模型包包含 `LSS.moc3`、`LSS.model3.json`、`LSS.physics3.json`、`LSS.cdi3.json` 和一张 4096×2048 纹理；纹理约 1.90 MiB。
- `model3.json` 声明了左右眼眨眼参数，没有声明动作文件、表情文件或命中区域。桌宠使用的 `cc_*.cfg` 不作为浏览器运行配置。
- `cdi3.json` 中有眼镜、脸红、“好耶”等命名参数，但其实际效果、范围和组合仍需运行验证。
- 桌子在纹理中是一块独立素材，可以将其对应像素精确改为透明，实现资源层面的视觉移除。当前只有导出的 `.moc3`，没有可编辑的 `.cmo3` 工程；纹理移除不会删除 `.moc3` 内的网格或减少其几何复杂度。
- 从纹理素材看，人物以半身构图为主。去桌子后必须检查躯干、手臂与下沿的完整性。
- 全站持久元素由 `src/layouts/Layout.astro` 编排；当前存在音乐悬浮组件，FAB 默认位于右侧。当前工作区已有 `src/data/music.ts` 的未提交修改。

## 实施顺序

### 1. 先做模型验证原型

1. 从桌面复制一份资源到开发验证目录，保留原文件，不修改桌面模型。
2. 优先验证 `pixi.js` 8.x + `untitled-pixi-live2d-engine` 1.4.0，通过其 `/cubism` 入口加载本模型所需的 Modern 支持，另行准备同源 Cubism Core。核实实际模型兼容性后锁定准确版本。
3. 在 4096×2048 原尺寸纹理上确认桌子的完整像素边界，只将该区域改为透明。保持其他区域、纹理尺寸、UV 布局和资源相对路径不变，不对整张纹理重新生成、缩放或重排；另保留原图和处理记录。
4. 用真实模型对比原始与去桌子版本，检查透明区域是否完整覆盖桌面、桌腿和边缘，以及手臂、衣服、杯子、头发和其他图块是否保持原样。保留原模型署名信息。
5. 验证默认姿态、视线跟随及点击表情，确认去桌子版本始终正确。当前方案不需要逐帧强制隐藏桌子；如果运行验证发现额外桌子素材，再核实对应纹理区域和绘制对象。
6. 同时确认半身下沿、参数范围、眨眼和物理效果，输出去桌子与原始状态的对照截图。实际改动仅应用于本站模型副本，不覆盖桌面原件。

阶段出口：真实模型能在浏览器渲染，去桌子纹理已验证且人物其他部分保持完整，半身构图可接受。如果去除后暴露明显模型缺损，先记录实际结果并调整方案，不以遮住桌面的裁剪冒充去桌子成功。若后续需要从结构中彻底删除桌子网格，取得 `.cmo3` 原工程后在 Cubism Editor 删除并重新导出，不直接篡改 `.moc3` 二进制。

### 库选型与安装安排

| 依赖 | 用途与约束 |
| --- | --- |
| `pixi.js` 8.x（满足引擎的 `^8.13.1` 要求） | Canvas/WebGL 舞台、变换和动画调度；与看板娘一起懒加载 |
| `untitled-pixi-live2d-engine` 1.4.0 | 加载模型、物理、跟随及参数控制；使用 `/cubism` 入口，避免引入旧版模型支持 |
| Cubism Core | 引擎仍需要的官方运行时，固定版本并同源部署，不由上述 npm 包替代 |

已通过模型原型验证，实际锁定 `pixi.js` 8.22.0 与 `untitled-pixi-live2d-engine` 1.4.0。上游文档提供 PixiJS v8、Cubism 3/4/5 入口和 4096px 纹理 LOD 能力；当前验证使用原尺寸纹理，实际是否采用降采样由后续画质对比决定，不能仅凭文档假定效果。

已核对 npm 元数据：`pixi-live2d-display` 的稳定版 0.4.0 仍依赖 Pixi 6，0.5.0-beta 才依赖 Pixi 7，不能与 Pixi 8 直接混装。原版库保留为兼容性备选，不同时安装多个 Live2D 封装。

引擎 1.4.0 的实际依赖包含 `@pixi/sound`，即使第一版不使用音频也要计入安装与产物评估；核对无音频入口的实际 bundle，不承诺安装后自动零音频代码。依赖已使用 `pnpm.cmd` 锁定并完成原型构建与静态加载检查，`package.json` 和 lockfile 已更新。

### 2. 建立可选功能与配置

建议以通用 `mascot` 领域承载能力，将伊蕾娜的模型资料与行为配置分开。

| 位置（拟定） | 职责 |
| --- | --- |
| `src/types/mascotConfig.ts` | 开关、桌面条件、尺寸档位、跟随与点击交互等行为类型 |
| `src/config/mascotConfig.ts` | 安全默认值、字段说明、`withUserConfig("mascot", ...)` 与 `resolveMascotOptions()` |
| `src/data/mascot.ts` | 伊蕾娜的名称、去桌子模型 URL、经验证的表情参数与构图信息 |
| `src/config/index.ts` | 配置导出 |
| `scripts/content/config-domains.mjs` | 注册 `mascot` / `config/mascot.yaml` 覆盖领域 |
| `src/components/organisms/mascot/Mascot.astro` | 配置短路、标签与样式隔离、按需引入交互入口 |
| `src/utils/mascot/` | 设备判断、状态保存、加载去重、运行生命周期与 Live2D 适配 |
| `src/layouts/Layout.astro` | 条件挂载于全站持久层 |
| `src/utils/mascot/labels.ts` | 集中的本站中文按钮、交互说明、加载失败和恢复入口文案，无十语言扩展 |

必要的交互 Svelte 组件位于同一 organism 目录，按实际需要引入，不新增没有复用需求的原子。通用默认关闭；开发验收显式开启，本站正式启用使用当前部署实际消费的配置入口，不手工编辑生成的 `src/user/user-config.ts`。

### 3. 接入加载与生命周期

- Astro 输出前按总开关短路；关闭时不输出人物、控制入口、特性样式或客户端加载脚本。
- 开启时先由轻量入口判断设备条件和访客收起状态，再延后加载 Web 运行库及模型。仅通过 CSS 隐藏不算手机端零模型下载。
- 运行库和模型使用确定的部署 URL，优先同源托管；首屏不预加载它们，构建不依赖临时外部服务。资源请求具有超时、去重及失效结果隔离。
- Swup 切页保留一个实例和一个动画循环。异步加载完成前若已收起或切换至不适用状态，不能重新挂载人物。
- 页面不可见或人物收起时停止动画；恢复时限制时间步长，避免物理跳变。缩至不适用宽度后清理运行实例，重新进入时可再次初始化。
- `prefers-reduced-motion` 下保留静态人物和控制能力，停用自动眨眼、呼吸、物理摆动及持续跟随。偏好动态变化时立即生效。
- 清理 Canvas、WebGL 资源、监听器与定时器；处理 WebGL 不可用或上下文丢失，避免自动重试循环。
- 使用项目 URL/base 工具解析模型入口；验证纹理、物理等相对路径在子路径部署下仍有效。
- 特性 CSS 与运行库不进入关闭状态的共享页面资源；遵守现有内联样式隔离与 `loadScriptOnce()` 约定。

### 4. 双模式与说明

核查源码模式和 `shirones` 包模式的配置覆盖、数据覆盖、资源地址及运行依赖。伊蕾娜是本站模型内容，不作为主题包强制下载的默认资源；包用户可以提供自己的模型 URL，缺失有效资料时不启动。若需要 integration 接线，修改唯一入口 `src/integration/`，不另写一套 `astro.config.mjs`。

同步配置目录说明，并补充看板娘使用说明与已验证的模型适配约定。依赖只安装在它实际需要的层级，不依赖本仓 devDependencies 偶然可用。

## 验收与验证

| 场景 | 通过条件 |
| --- | --- |
| 真实模型 | 桌子在默认姿态、表情和跟随时均不可见；无人物误隐藏或突兀截断；保留截图证据 |
| 展示与操作 | 明暗主题、宽屏与较窄桌面、缩放、收起、刷新恢复均正常；不遮挡正文、音乐条、FAB 与覆盖层 |
| 设备与关闭 | 功能关闭时零特性 DOM、零特性运行资源；手机和平板不请求 Live2D 运行库、模型与纹理 |
| Swup | 首页直达、文章直达、首页到文章及返回，始终只有一个 Canvas、一个运行实例，无重复资源初始化 |
| 异步与失败 | 慢加载时收起、资源 404、WebGL 不可用均不影响阅读，不出现迟到的人物或无限重试 |
| 动态偏好 | 后台与收起时无持续动画循环；减少动态效果模式停用自动运动，控制功能仍可用 |
| 生产与包模式 | 生产构建、子路径资源、配置覆盖及用户自备模型路径可用，关闭状态不加载专用 CSS/JS |

实现后新增针对这些用户行为的 `tests/site/mascot.spec.ts`；重点覆盖设备请求、状态恢复、导航单实例、关闭状态和异步收起竞态。真实模型截图与浏览器操作用于确认 WebGL 渲染效果，不以 mock 代替去桌子验证。

运行 `npx.cmd astro check`、相关 Playwright 分片及 `tests/site/a11y.spec.ts`；浮层和动态行为变化时补相关 FAB、音乐、motion 分片。执行生产构建及关闭状态产物检查；依赖与包接线变化时运行 `pnpm.cmd type-check`、`pnpm.cmd check:package-manifest`，并做包模式 smoke 验证。按项目要求执行 `fonts:check` 与 `perf:measure`，比较启用前后指标和请求，关注 LCP、CLS 及持续渲染开销。
